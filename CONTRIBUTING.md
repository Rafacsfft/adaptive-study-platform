# Contributing

AdaptEd is validating its first study loop, so focused contributions are more useful than large feature additions.

1. Open an issue describing the problem and expected outcome.
2. Keep the change small and connected to an existing goal.
3. Run `npm run lint` and `npm test`.
4. Explain what changed and how you verified it.

Do not include private student data, copyrighted question banks, API keys, or invented user results.
